## Step 11 Final Form — Two-Tier

### Case p/q < 1: Hard Mathematical Exclusion [UNCONDITIONAL]
Any mechanism fixing β = (p/q)·2π with p/q < 1 requires S to have imaginary period
(p/q)·2πi. S has minimal imaginary period exactly 2πi (minimal period of exp is 2πi;
no entire function with minimal period 2πi has a smaller period). Mathematically impossible.
This exclusion is independent of V4's principles — it is a fact about the exponential function.

### Case p/q > 1: Self-Bounding Exclusion [V4-INTERNAL]
Would use non-minimal period n·2πi (n > 1). The minimal period 2πi is already in the
derived structure of S. The same logic that fixes β = n·2π via n·2πi equally fixes β = 2π
via 2πi — without introducing n. Self-bounding (FP) excludes over-specification: using
n·2πi when 2πi suffices introduces n beyond what is required.
NOT a hard mathematical impossibility — rigorous within V4's framework.

### Case p/q = 1: Unique Surviving Case
β = 2π. Uses S's minimal period exactly. Not excluded by either argument.
