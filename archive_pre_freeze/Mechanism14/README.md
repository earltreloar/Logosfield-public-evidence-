# Mechanism #14 — Biological Archetype Recurrence

**Goal**  
Test evolutionary recurrence of symbolic/biological traits under a Logosfield archetype model.

**Data**  
10-trait panel spanning phylogenetic and symbolic lineages.

**Method (locked/prereg)**  
Fisher combined p across traits with prereg nulls; trait-rank correlation as secondary.

**Key result**  
Combined **p ≈ 1.9×10⁻¹²** (7/10 traits significant).

**Reproduce**  
- Runner: `python run.py --mechanism 14`  
- Bundle: `Mechanism14_BiologicalArchetype_Results.zip`

**Outputs**  
Trait tables, per-trait stats, Fisher summary JSON in `Mechanism14/outputs/`.
